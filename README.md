# İstikbal Bayi Finans & Karlılık Merkezi

Bu paket GitHub Pages üzerinde doğrudan çalışır.

## GitHub'a koyma
1. GitHub'da yeni bir repository oluşturun. Örnek: `istikbal-finans`
2. Bu klasördeki 3 dosyayı repository'ye yükleyin:
   - index.html
   - style.css
   - app.js
3. GitHub > Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. Save
7. Birkaç dakika sonra GitHub size internet adresini verir.

## İlk sürüm
- Patron ekranı
- Banka + kasa
- Gerçek serbest para
- Yaklaşan ödemeler
- 60 günlük nakit görünümü
- Ürün gerçek karlılığı
- Lojistik / konteyner maliyeti
- m3 başına lojistik
- Gider ve ödeme önceliği
- JSON yedek alma / geri yükleme
- Finans uzmanı yorumları

## Önemli
Bu ilk sürüm verileri tarayıcının LocalStorage alanında saklar.
Yani başka bilgisayarda otomatik görünmez. "Yedek Al" ile JSON yedeği alın.

Sonraki aşamada mevcut müşteri programının veritabanına bağlanarak:
- satışlar,
- tahsilatlar,
- müşteri bakiyeleri,
- satılan ürünler
otomatik olarak finans paneline aktarılabilir.

Bu uygulama resmi muhasebe yazılımının yerine geçmez; işletme içi yönetim ve nakit karar desteğidir.
